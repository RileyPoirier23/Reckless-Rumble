# Vehicle Customization Mock-ups

These SVG sheets are **review concepts**, not final runtime assets. They use crisp integer geometry and fictional branding so the art direction can be approved before producing 16-slice runtime stacks.

## Nissun Silvio

- Stock: factory body, stock ride height, silver cross-spoke wheels.
- Street: front lip, side skirt, ducktail, bronze wheels, lowered stance, visible intercooler.
- Drift: wide fenders, vented hood, pedestal wing, deep-dish wheels, side exit, original diagonal livery.

## Fjord Ranger XL

- Stock: factory half-ton body, steel-style wheels and standard ride height.
- Off-road: raised suspension, mud tires, beadlock-style wheels, tubular bumpers, roll bar, roof lights and bed spare.
- Low: lowered suspension, smooth body-color treatment, tonneau cover, polished street wheels, low-profile tires and dual exhaust.

## Approval Notes

- The sheets intentionally use labels and a dark presentation field; final source sprites must be transparent and label-free.
- Final showroom files will be 256×96 PNGs on a common baseline.
- Final runtime cars still require 16 aligned slices, light masks, detachable bumpers, steerable front wheels, paint masks and directional-damage testing.
- Names, silhouettes and details are fictional parodies; do not add real logos, sponsor marks or copied liveries.
